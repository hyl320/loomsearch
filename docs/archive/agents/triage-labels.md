# Triage 标签

技能内部用五个规范 triage 角色来沟通。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 技能里的标签（mattpocock/skills） | 本仓库实际标签 | 含义 |
| -------------------------------- | -------------- | ---- |
| `needs-triage`                   | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info`                     | `needs-info`   | 等待报告者补充信息 |
| `ready-for-agent`                | `ready-for-agent` | 已完全明确，可交给 AFK agent |
| `ready-for-human`                | `ready-for-human` | 需要人工实现 |
| `wontfix`                        | `wontfix`      | 不处理 |

当技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用本表对应的标签字符串。

右列可以改成你实际使用的标签词表。
