# 模拟面试结果：概念骨架稳，三处口头表达需打磨

10 题模拟面试里，用户对「两个句柄」「prepared statement 防注入」「WAL 快照」「parity 条件」等答得较扎实，说明 FTS5 / 倒排索引的核心概念骨架已经建立，且能脱离代码口头表达。

仍需打磨的三处：① 把「存的数据」和「算的结果」混淆（反复说 FTS5 存了权重 / idf，实际是存词频和位置、查询时才算 BM25 / idf）；② 分词方向说反（把 unicode61 的「去重音」说成「支持重音」，且分不清中文在 ASCII 分词下是「切不出词」、在 unicode61 下是「连续中文成一个 token 但不分词」）；③ 自贬用词（把自己手写实现说成「玩具」，面试里应换成「为了吃透原理」的正面表述）。
